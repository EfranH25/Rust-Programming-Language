# The Rust Programming Language

Hello world :)

This repo is a personal learning repository containing code written while reading through [*The Rust Programming Language*](https://doc.rust-lang.org/book/) (the official Rust book) by Steve Klabnik and Carol Nichols.

## About

This repo tracks my progress through the book chapter by chapter. Each section contains code examples, exercises, and experiments written as I worked through the material.

This repo marks the start of a long & productive journey programming in Rust!

## Topics Covered

- Ownership, borrowing, and lifetimes
- Structs, enums, and pattern matching
- Error handling with `Result` and `Option`
- Generics and traits
- Closures and iterators
- Smart pointers
- Concurrency
- Async/await
- And more...
